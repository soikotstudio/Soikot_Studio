# Soikot Studio

A high-end editorial digital agency website featuring interactive WebGL/3D aesthetics, full-bleed scroll-pinned disciplines, depth flip case study carousels with hover-blur reveals, custom video showcase player, and mechanical slot-counter metrics.

## Tech Stack
- **HTML5 & CSS3** (Custom Design Tokens, Fluid Typography, Micro-Interactions)
- **Vanilla JavaScript** (Scroll-driven animations, Interactive Carousel, Video Lightbox, Mechanical Counter)
